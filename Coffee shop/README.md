# Enaco Café ☕

A modern, responsive, and visually appealing web application for **Enaco Café**. Experience handcrafted coffee, freshly roasted beans, and gourmet cuisine in an elegant online atmosphere.

## 🌟 Features

- **Responsive Header & Navbar**: Smooth navigation across all sections.
- **Interactive Hero & Menu**: Highlights featured coffee blends, beverages, and cuisine.
- **Modern UI Design**: Elegant layout crafted with HTML5, custom CSS3, and JavaScript.
- **Fast & Lightweight**: Standard web technologies with zero build steps or heavy dependencies.

## 📁 Project Structure

```text
├── index.html        # Main HTML document
├── style/
│   └── style.css     # CSS design tokens & styling
├── script/
│   └── main.js       # Interactive JavaScript functionality
└── asset/            # Images, icons, and media assets
```

## 🛠️ Built With

- **HTML5**: Semantic elements and structured layouts.
- **CSS3**: Custom variables, responsive design, and smooth animations.
- **JavaScript (ES6+)**: Dynamic interactivity and UI components.
